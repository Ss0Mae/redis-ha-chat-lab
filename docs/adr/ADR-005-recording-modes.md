# ADR-005 실험 기록은 요청 경로에서 분리한다

**상태**: 채택 (2026-09-05)

**문제**: 요청마다 MySQL 에 쓰면 Redis 명령(수백 µs)보다 기록(수 ms)이 비싸 측정을 망친다. 반대로 정합성 실험은 승인된 쓰기 전부를 추적해야 한다.

**선택**: 세 가지 모드를 두고 실험 생성 시 고른다.
- `MEMORY` — 요청은 `LongAdder`·지연 큐에만 남기고 1초마다 1행(`metric_sample`)만 저장. 성능 비교(k6) 기본값.
- `BATCH` — 요청마다 행을 유계 큐(20만)에 넣고 별도 스레드가 500행씩 `batchUpdate`. 정합성 실험 기본값. 큐가 차면 버리고 `recordingDropped` 로 센다.
- `SAMPLED` — 1/100 요청만 행 저장 + 1초 집계.
승인 쓰기 장부(`Ledger`)는 모드와 무관하게 메모리에 두어 Failover 후 대조가 DB 없이 끝난다.

**검증 방법**: 같은 300 RPS 에서 모드만 바꿔 Redis 명령 p95 와 앱 CPU 를 비교한다(결과는 `docs/results.md`).
